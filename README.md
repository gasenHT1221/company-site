# スカイライン・テクノロジーズ コーポレートサイト

スカイライン・テクノロジーズのコーポレートサイトです。業務システムから SaaS、クラウド基盤まで手がけるソフトウェア開発会社として、事業内容や実績を紹介します。

## サイト概要

1 ページ構成の静的サイトで、`index.html` 1 ファイルに HTML・CSS・JavaScript をまとめています。ビルドや依存パッケージのインストールは不要です。

ページは次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと会社の紹介 |
| サービス (`#services`) | 提供しているサービス |
| 導入実績 (`#works`) | これまでの導入事例 |
| 開発の進め方 (`#process`) | プロジェクトの進行ステップ |
| 会社概要 (`#company`) | 会社情報 |
| お問い合わせ (`#contact`) | 問い合わせ窓口 |

フォントは Google Fonts（Zen Kaku Gothic New、Bricolage Grotesque、JetBrains Mono）から読み込んでいます。オフライン環境ではブラウザ標準のフォントで表示されます。

## ブラウザで表示する手順

### 方法 1: ファイルを直接開く

1. このリポジトリをクローン、またはダウンロードします。
2. エクスプローラー（Windows）や Finder（macOS）で `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法 2: コマンドラインから開く

リポジトリのディレクトリで次のコマンドを実行します。

```sh
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 方法 3: ローカルサーバーで開く（任意）

`http://` の URL で確認したい場合は、簡易サーバーを起動します。

```sh
python3 -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000> を開きます。終了するときは `Ctrl + C` を押します。
